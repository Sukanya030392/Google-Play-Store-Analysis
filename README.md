# **Google Play Store Data Analysis**



###### **Project Overview**

This project analyses Google Play Store applications to understand app categories, ratings, installs, reviews, and pricing. The goal is to identify patterns in app popularity and user engagement.



###### **Tools Used**

\- Python — Data cleaning and exploratory data analysis (EDA)

\- SQL (MySQL) — Data querying and analysis

\- Power BI — Dashboard creation and visualisation

\- Excel/CSV — Dataset handling



###### **Project Objectives**

\- Analyse the distribution of apps across categories.

\- Compare app ratings across categories.

\- Identify apps and categories with high installs.

\- Compare free and paid applications.

\- Understand the relationship between reviews and installs.



###### **Key Findings**

\- Family has the highest number of apps in the dataset.

\- Games have the highest total installs.

\- Events has the highest average rating among the categories analysed.

\- Free apps have a higher median install count than paid apps.

\- Apps with more installs tend to receive more reviews.

\- App size alone does not determine popularity.

###### **Conclusion**

This project helped explore app performance using data cleaning, SQL queries, exploratory analysis, and interactive visualisations. It highlights patterns in app popularity, ratings, and user engagement.
